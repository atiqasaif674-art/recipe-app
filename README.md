# 🍳 Recipe App

A simple and responsive **Recipe App** built with **React.js**.
Users can search for recipes, browse available recipes, and view detailed recipe information.

## 🚀 Features

* 🔍 Search recipes by name
* 🍽️ Display recipe cards
* 📖 View complete recipe details
* 📱 Responsive design
* ⚛️ Built with React components
* 🎨 Clean and simple UI
* 📂 Organized component-based structure

## 🛠️ Technologies Used

* **React.js**
* **JavaScript (ES6+)**
* **HTML5**
* **CSS3**
* **Vite**
* **Git & GitHub**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/atiqasaif674-art/recipe-app.git
```

Go to the project folder:

```bash
cd recipe-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in your terminal.
